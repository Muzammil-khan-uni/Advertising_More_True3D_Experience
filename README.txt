INTERACTIVE SOURCE
For full WebGL 3D and service catalogue, open INTERACTIVE_3D_PREVIEW_OFFLINE.html in an updated Chrome, Edge, Safari or Firefox browser with WebGL enabled. A GPU-capable browser is needed to run the 3D renderer. If WebGL is disabled, the page displays an intentionally designed illustrated fallback (with subtle CSS animation) rather than a blank canvas.

To run the modular version:
1. Open a terminal in this folder.
2. Run: python -m http.server 8000
3. Visit http://localhost:8000

HOW TO USE
- Move or drag inside the hero 3D viewport to orbit the party scene.
- Click PAUSE / PLAY to stop and resume object animation.
- Double click the scene to reset the orbit.
- Search / filter the service catalogue and use + to save experiences.
- Review your shortlist, fill in an event brief, and copy it to contact Advertising & More separately.

3D SCENE DETAILS
The WebGL animation does NOT rotate one flat PNG. The following are actual WebGL meshes with independent transforms and lighting:
- Golden cup + saucer, coffee surface, ceramic handle, foam heart, brand lettering.
- Tiled spinning mirror ball and rotating golden torus.
- Separately moving metallic balloons, thick stars, party-confetti pieces.
- Arcade joystick, buttons, plinth, neon carnival rings and round stage.
- CSS-generated coffee steam overlays the 3D scene.

The page uses a custom lightweight vanilla JavaScript WebGL renderer without CDN imports. The existing 100-experience catalogue is retained with category filtering, favourites, detailed views and an event-planning interface.

QA / HONEST LIMITATION
Desktop (1600px) and mobile (390px) fallback renders were tested: no browser JavaScript errors or sideways overflow; 100 items are loaded, and search, load more, details, shortlist and mobile menu interactions work.
The automated testing browser does not expose a WebGL context, so actual GPU rendering has NOT been browser-validated in this environment. Real WebGL 3D runs only in browsers where WebGL is enabled; verify in an updated Chrome/Edge desktop browser before claiming GPU 3D is fully production validated.
This is a front-end design proposal, not a production booking website. The enquiry creates a copyable brief but does not send data or reserve equipment. Logo / coffee illustration are used for the expressly requested concept for the existing brand. Non-official created visuals are conceptual, and service availability must be confirmed by the client.
